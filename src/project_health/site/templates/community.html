Review responsiveness

How quickly a patch submission gets its first visible review response, split by how many prior submissions the same contributor has -- a first-time submitter, a 2nd-5th submission, or a 6th+ submission. A "submission" is one JIRA issue that ever reached Patch Available, together with any linked GitHub pull request. "First visible response" is the earliest of a JIRA comment, a JIRA status change to Review In Progress/Ready to Commit, or a GitHub PR review/comment, from someone other than the submission's own author -- review that happened somewhere this project doesn't track (a private message, an in-person conversation) is invisible to this section, so "no visible response" means exactly that, not "no response at all."

Methodology and caveats. The submission's author is reconstructed from JIRA's assignee-change history, which is a best-effort proxy, not a confirmed identity. Shares for "response within 7/30 days" and "no visible response" only count submissions old enough to judge (right-censoring: a submission newer than 7, 30, or 365 days is left out of that share's count entirely, not counted as a miss). These figures are informational only -- they are not part of this site's composite score, and are shown with their own sample size (n) for context. Full definitions: METRICS.md.
