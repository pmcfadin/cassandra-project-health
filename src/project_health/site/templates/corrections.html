What happens next

  • A maintainer of this project reviews the issue.
  • A data or identity fix lands as a pull request to a config file — e.g. identity_overrides.yaml or governance_overrides.yaml — and shows on the site after the next nightly run, once merged.
  • A classification disagreement (conversation patterns, thread explorer) feeds the classification-cutoff calibration work tracked in issue #47, rather than being hand-overridden one message at a time.
